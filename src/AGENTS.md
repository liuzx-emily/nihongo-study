# 前端源码规范

本目录保存 Vue 3 + Vite 前端源码，并继承根目录的请求分类、电脑端平台约束和内容保护规则。

## 代码组织

- 使用 Vue Composition API 与 `<script setup lang="ts">`。
- 保持完整、明确的 TypeScript 类型，仅在确有必要时使用 `any`。
- 页面级组件放在 `views/`，可复用组件放在 `components/`，学习档案放在 `content/`。
- 学习内容通过档案数据提供，不硬编码到页面组件。
- 优先复用现有类型、组件、样式体系和 CSS 变量。

## 实现质量

- 组件职责、状态流向和命名保持清晰，避免为单一场景复制已有逻辑。
- 样式服务于信息层级、可读性和紧凑的电脑端布局。
- 交互使用语义化 HTML，并支持电脑端键盘操作和清晰的焦点状态。
- 修改类型或档案结构时，确保所有既有文章仍能渲染。
