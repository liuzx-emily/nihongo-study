# 网页开发规范

本目录是 Vue 3 + Vite 前端源码。

- 使用 Vue Composition API 和 `<script setup lang="ts">`；
- 保持 TypeScript 类型完整，不使用无必要的 `any`；
- 页面级组件放在 `views/`；
- 可复用组件放在 `components/`；
- 学习内容数据放在 `content/`，不得硬编码进页面组件；
- 视觉调整优先使用现有 CSS 变量；
- 保持电脑端键盘操作和语义化标签；
- 只实现宽度不小于 1180px 的电脑端布局，禁止添加任何移动端适配、窄屏断点或触控专用逻辑；
- 样式以高信息密度和可读性为准：删除纯装饰元素、超大展示区、无意义动画和过量留白，让首屏尽可能多地呈现有效内容；
- 优先复用现有类型、组件和样式体系；
- 完成修改后运行 `npm run build`；
- 不擅自改动学习内容的日文、翻译和教学解释。
