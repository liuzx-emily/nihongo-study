# STUDY 模式规则

本文件仅适用于 `STUDY` 请求。

## 学习处理

- 目标用户已通过 N4、正在学习 N3；重点讲解进阶表达、重要口语、语境用法和句子逻辑。
- 处理新稿、续写档案或整理语法前，必须读取根目录 `LEARNING_PROFILE.md`，并按其中的语法家族和例外规则筛选讲解项。
- 日文稿处理属于忠实校对，不是改写、缩写或总结。修正后的日文必须仍能逐句对应原稿，保留原有信息、论述顺序、例子、语气和说话人立场。
- 中文翻译必须保持原文的叙述视角、人称和话语层级。主播以第一人称直接讲述时，译文也使用第一人称或保留原文的无主句，不得改写为“主播说／主播认为／据主播叙述”等第三人称转述；原文省略主语时，延续当前说话人的视角。只有原文明示切换到第三人称或引用他人观点时，才可改变人称或话语层级。
- 采用最小必要修正：只有能够从上下文可靠确认的自动转写错误、明确口误、错别字、标点或断句问题才可修改；能成立的原句一律保留，即使表达重复、绕口、不够精练或不符合书面语习惯。
- 保留自然口语中的重复、停顿、插入语、自我修正、话题跳转、语气词、犹豫和未说完的结构。不得为了流畅而删句、合并句子、调整顺序、补充逻辑、替换成概括性表达或统一成书面语。
- 只有确认是转写系统造成的无意义重复或噪声时才可删除；无法区分转写错误、说话人口误和自然口语时，保留原文并标记存疑。
- 修正不得引入原稿没有的事实、因果关系、评价或结论。若一句话需要较大改写才能变得自然，不作改写，保留原句并在讲解中说明问题。
- 无法可靠确认的内容明确标记存疑，不得补写猜测内容。
- 按语意划分 `section`，每个 `section` 的日文原则上为 300～1000 字符。`section` 是围绕同一局部主题组织的学习单元，不等同于单个自然段。
- 一个 `section` 内可包含一个或多个自然段，每个自然段的日文原则上不超过 200 字符。应根据原稿段落、话题推进、说话人轮次、过渡和自然停顿划分自然段，不得把超过 200 字符的连续正文无差别合并成一段，也不得为了满足字数而截断句子或机械切碎连续语意。
- 日文与中文翻译使用对应位置的换行表示自然段，段落数量、顺序和内容须一一对应，不得一侧分段而另一侧合并。
- 每个 `section` 提供修正后的完整日文、完整中文翻译、词汇、语法与口语结构。
- 完成每个 `section` 后对照原稿复核：原稿中的每个实质信息、例子、限定、转折、语气和立场都必须在修正稿中保留；中文翻译也必须完整对应，不得用归纳或总结代替原文内容。
- 交付前复核自然段结构：逐个检查 `section.japanese` 与 `section.translation` 的换行是否一一对应，并检查是否根据语意保留了合理的内部自然段、每个日文自然段是否原则上不超过 200 字符。若一篇包含多个 `section` 的文章机械地全部只有一个自然段，或存在超过 200 字符却没有合理分段的自然段，必须视为结构异常并重新逐段复核。
- 交付前检查中文翻译是否擅自从文本外部指称当前说话人，或添加原文没有的归因表达，例如“主播说”“作者认为”“据讲述者叙述”。发现此类表达时，必须恢复为原文的直接叙述，并核对原文第一人称及上下文省略的第一人称没有被译成第三人称。
- 词汇和语法记录表达、读音、释义、接续及语境说明；不记录或展示 JLPT 等级。
- 普通 N5、N4 内容不作讲解，除非在当前语境中有特殊用法。
- 用户明确表示某语法“已掌握／以后不用讲”时，将其归一到 `LEARNING_PROFILE.md` 的语法家族后记录；表示“还不熟／需要复习”时移除或缩小对应覆盖范围。
- 不根据文章完成度、出现次数或过往讲解记录自动判定语法已掌握。
- 长稿可分批处理，并准确记录续接位置。
- 单个知识点问答直接在对话中完成；除非用户要求写入档案，否则不修改项目文件。

## 档案触发与验证

- 用户发送完整新稿并要求“处理”，等同于要求完成学习处理并保存为网页档案。
- “生成档案”“加入网页”“保存这篇稿子”等明确要求均触发持久化。
- 同一稿件的后续批次追加到原档案；创建前检查现有内容，避免重复或覆盖。
- 只引用内容、询问知识点或明确要求仅在对话中处理时，不持久化。
- 修改档案数据后运行 `npm run build`。

## 当前文章判定

按以下顺序确定后续问题所指文章：

1. 用户明确给出的文章名称；
2. 用户引用的原句；
3. 当前对话最近处理的稿件；
4. `src/content/` 中最近更新且 `status` 为 `进行中` 的档案。

以上信息仍不足时，再询问用户。不要把当前文章名称写入指令文件。
# 默认处理范围

- 未明确触发长稿流程时，在当前主对话中按本文件规定的原有流程一次性处理，不主动读取或调用长稿编排规则。
- 只有用户明确表示文章太长并要求分段处理时，才由主代理按根目录 `AGENTS.md` 的二级路由另行读取 `instructions/STUDY_LONG.md`。
