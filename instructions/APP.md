# APP 模式规则

本文件仅适用于 `APP` 请求。

## 电脑端平台约束

应用仅为宽度不小于 1180px 的电脑屏幕设计和验收。

- 使用稳定的电脑端布局；屏幕不足 1180px 时允许横向滚动，不改变内容、栏位或导航结构。
- 项目中不得包含面向手机、平板、触控设备或窄屏的适配代码，包括窄屏媒体查询、移动端 viewport、触控或屏幕方向分支、安全区域变量，以及移动端专用组件和样式。
- 每次修改应用后检查上述限制，并在交付前移除不符合要求的代码。
- 只有用户明确要求修改本节约束时，才可改变目标平台。

## 应用规则

- 保持 Vue 3、Vite 和 TypeScript 技术栈，优先复用现有类型、组件、数据结构和样式变量。
- 应用修改不得擅自改变日文原稿、翻译或教学解释，也不得覆盖已有学习档案。
- 数据结构变更必须兼容已有档案。
- 界面以学习内容和操作为中心，在不牺牲字号、行距、可读性和信息层级的前提下提高信息密度。
- 标题、元数据、搜索、导航和学习内容均属于有效信息；使用紧凑间距、字重、颜色和分隔线建立层级。
- 不使用纯装饰纹理、印章、超大展示区、空洞标语、无意义动画或过量留白。页面调整后检查首屏空间利用率。
- 保持语义化标签及电脑端键盘操作能力。
- 修改应用代码后运行 `npm run build`。
